# 照片轉方塊

把照片變成方塊風格的 2D 像素馬賽克、拼豆／積木施工圖，以及可以 360° 旋轉的 3D 方塊作品。給國小課堂使用（數學面積與比例、美術像素畫、拼豆手作）。

線上使用：https://upsky0210.github.io/photo-blocks/

## 功能
- **方塊人偶**（第一個分頁）：先選人或小動物，再放照片。自動取膚色、髮色與衣服顏色，辨識髮長、袖長及裙褲；動物支援主色與花色初稿。辨識結果可以自由改，失敗也能直接創作。
- 人偶可選髮型、帽子、上衣、裙褲、圍巾、背包、哨子、眼鏡、左右手拿物；動物可選貓、狗、兔子、鳥、倉鼠、烏龜、蜜袋鼯。所有角色可切換八種像素表情，**不重現照片五官**。
- 部位色票、點原始照片吸色、隨機搭配、重新辨識；動物沒認出來時，可切換小動物後直接點照片中的動物。
- 人偶展示台、360° 旋轉縮放、自動旋轉、點一下揮手與跳躍。可匯出附暱稱的角色卡 PNG、GLB、STL、USDZ／AR，以及可重新開啟修改的角色 JSON（不含照片）。
- 拍照、選照片、拖曳或貼上圖片；也有程式畫的範例圖可以先試
- 2D 馬賽克：橫向 16～128 格、4／8／16／32 色、五種調色盤（原圖自動取色、方塊遊戲風、拼豆色、積木色、灰階），用 Lab 色彩空間比對顏色；格線每 10 格一條粗線
- 下載 PNG（有格線／無格線）
- 色塊統計：每種顏色幾格、佔多少
- A4 施工圖列印：第 1 頁是總覽和色號表，之後每頁 30×38 格，格子裡標號碼
- 3D 方塊：平面／越亮越高／越暗越高、高度倍率、自動旋轉；滑鼠和兩指觸控都能旋轉縮放
- 3D 匯出：截圖 PNG、GLB、STL（封閉實體，可直接 3D 列印）、USDZ；iPad／iPhone 可以直接用 AR 擺在桌上看

## 隱私
全部在瀏覽器裡處理，照片不會上傳，不用登入，也沒有後端。

## 檔案
- `index.html`：版面與樣式（含列印樣式）
- `js/app.js`：介面、讀照片、統計、施工圖
- `js/mosaic.js`、`js/color.js`、`js/palettes.js`：切格子、取色、調色盤
- `js/view3d.js`：原有浮雕 3D 畫面與匯出
- `js/figure/`：人偶介面、模型、辨識、展示與封閉實體 STL；校園模型來源標在檔案開頭
- `vendor/mediapipe/`：MediaPipe Tasks Vision、WASM、四個模型與授權；只在進入人偶分頁後載入，不依賴 CDN
- `vendor/three/`：three.js r160（MIT，放在 repo 裡，不依賴 CDN）
- `fonts/`：俐方體 11 號（SIL Open Font License，授權檔 `Cubic_11-OFL.txt`）

拼豆色、積木色的色號是本工具自己編的，不是任何廠牌的官方色號。

## 人偶辨識與列印說明
MediaPipe Tasks Vision 版本固定為 `0.10.22-rc.20250304`。模型由本站載入並使用瀏覽器快取，照片不會送往模型提供者。首次辨識會顯示下載進度；模型依序執行，GPU 失敗改 CPU。照片最長邊仍先縮為 768 像素。辨識髮型、衣服與花色只是初稿，帽子和配件由學生選。插畫若有人物框但缺少可靠的臉／頭髮分割，會依人物區域近似取膚色、髮色和衣服顏色，並明確提示確認；GPU 回傳空白區域時也會用 CPU 再確認。姿勢模型失敗時仍保留已取出的顏色。

半身照或無法確認膝蓋、腳踝都在照片內時，下半身先用黑色長褲；可手動選擇長裙、長褲、短裙、短褲，上衣與下半身都有獨立色票。另提供背心疊穿長袖與袖子顏色。舊角色 JSON 的褲子／裙子設定仍可開啟。

人偶 STL 會將零件合成體素實體，補強細小配件、為懸空部分加支柱，匯出前檢查每條邊由兩個反向三角形共用及正體積。最長邊 100 mm；表面細節採方塊近似，與彩色模型略有不同。GLB／USDZ 以公尺為單位。

## 開發驗證
維持純靜態網站，無建置步驟。用 `python -m http.server 5180` 開啟本機網站。

`tests/` 的瀏覽器測試需開發環境已有 Playwright（可用 `PLAYWRIGHT_MODULE` 指定套件位置、`BROWSER_EXE` 指定瀏覽器），不影響網站執行：
- `node tests/smoke.cjs`：範例圖、辨識失敗退回手動、768×1024 與外部請求檢查。
- `node tests/figure.cjs`：JSON 往返、照片吸色、手拿物封閉實體、CPU 模型與版面。
- `node tests/exports.cjs`：PNG／GLB／STL／USDZ、七種動物、原有馬賽克／浮雕與施工圖。
- `node tests/mask.cjs`：互動分割遮罩輸出的診斷。
- `node tests/portrait.cjs`：程式插畫取色、半身判斷、四種下半身實體與上衣調色（可另用 `REFERENCE_IMAGE` 指定本次回報的插畫截圖做本機驗證，不會複製進專案）。
- `node tests/fallback.cjs`：延遲載入、GPU 改 CPU、模型下載失敗與互動取色。

已以桌機 Chrome 及 768×1024 視窗驗證。**待實際 iPad Safari 驗證**：拍照、觸控旋轉縮放、人物／動物辨識準確度與記憶體、AR Quick Look、下載與列印；也尚未實體列印小公仔。
